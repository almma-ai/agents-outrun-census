Get out of this number

Add a charter and the badge. A charter.json following the Delegation Charter Specification moves an agent from scanned to self-certified, and the badge charter v1.0 · score 00 enters it in the index by choice.

Method

Every month a script runs the open-source diagnostic against agent definitions that are already public: GitHub code search for each framework's configuration file, the MCP registry, npm and PyPI. Each file becomes one or more agents by a fixed unit rule. Each agent is read for the eight pillars of the Delegation Charter. Structural facts (tools held, deny lists, interrupts, CODEOWNERS) are exact; instruction-text patterns are English-only and reported as upper bounds. No project, repository, maintainer or user is named; identifiers are hashed before storage.
